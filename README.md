## About Zenkai

[**Zenkai**](https://zenkai-streaming.vercel.app/index.html) is a complete ecosystem uniting **Animes, Cartoons, Movies, Mangas, Comics (HQs), Games, and Artificial Intelligence (ZenkAI)** into a single immersive experience.

This official VS Code theme brings the vibrant cyberpunk and neon aesthetic of the Zenkai platform directly into your code editor. Designed for developers, creators, and marathon coders who want high contrast, reduced eye strain, and a futuristic visual environment.

---

## Key Features

- **Electric Purple Dominance**: Built around a signature `#612BFF` deep neon purple core.
- **Neon Cyan & Pink Accents**: Highlighting code structures with sharp `#00F0FF` cyan and `#FF007F` magenta tones.
- **Deep Space Background**: Low-light navy background (`#110A26`) tuned for night sessions and focus.
- **Comprehensive Syntax Coverage**: Tailored colors for JavaScript, TypeScript, Python, HTML, CSS, JSON, Rust, Go, and more.

## Installation

### From VS Code Marketplace

1. Open **VS Code** and go to **Extensions** (`Ctrl+Shift+X` or `Cmd+Shift+X`).
2. Search for **`Zenkai Theme`**.
3. Click **Install**.
4. Go to **File > Preferences > Color Theme** and select **Zenkai Dark**.

### Manual VSIX Installation

```bash
code --install-extension zenkai.zenkai-vscode-extension
```
