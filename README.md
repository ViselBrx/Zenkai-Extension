## About Zenkai ^_^

[**Zenkai Theme**](https://zenkai-streaming.vercel.app/index.html) is a neon visual ecosystem inspired by the Zenkai universe — a place built around anime, cartoons, movies, manga, games and artificial intelligence.

This official VS Code extension brings that atmosphere into your editor with deep dark backgrounds, expressive syntax colors and carefully tuned contrast for focused coding sessions. It is designed for developers who want their workspace to feel personal, energetic and unmistakably neon.

## The Themes

The free extension includes 11 color variants built on top of the signature ultra-deep dark background:

### Standard Neon Collection

- **Zenkai Neon Cyan** (`#72FFFF`) — crisp and futuristic.
- **Zenkai Neon Green** (`#00FF00`) — classic hacker and Matrix energy.
- **Zenkai Neon Yellow** (`#F5E200`) — bright, focused and high-energy.
- **Zenkai Neon Red** (`#FF0000`) — bold, intense and aggressive.
- **Zenkai Neon Purple** (`#A000FF`) — deep cyberpunk atmosphere.
- **Zenkai Neon Orange** (`#FF7A20`) — warm, fiery and dynamic.
- **Zenkai Neon Blue** (`#2979FF`) — cool, calm and focused.
- **Zenkai Neon Dark Green** (`#1F6E52`) — subdued forest neon tones.
- **Zenkai Neon White** (`#FFFFFF`) — pure contrast and minimalism.
- **Zenkai Neon Aqua** (`#3FF2A0`) — refreshing tropical cyber-vibes.
- **Zenkai Dark** — the original theme, kept for backwards compatibility.

### Zenkai Theme Pro

The separate **Zenkai Theme Pro** package adds premium color themes, a neon developer file icon system and a custom product icon theme for the VS Code workbench.

## Installation

### From VS Code Marketplace

1. Open **Extensions** (`Ctrl+Shift+X` or `Cmd+Shift+X`).
2. Search for **Zenkai Theme**.
3. Click **Install**.
4. Open **Preferences: Color Theme** and select your favorite Zenkai theme.

### From Open VSX Registry

The extension is also available through the [Open VSX Registry](https://open-vsx.org/extension/zenkai/zenkai-vscode-extension) for VSCodium, Cursor, Antigravity and other compatible editors.

### Manual VSIX installation

```bash
code --install-extension zenkai.zenkai-vscode-extension
```

## Recommended Setup

For the complete Zenkai experience, pair a color theme with the matching editor settings:

- Choose a dark VS Code base theme.
- Select one of the Zenkai Neon color variants.
- Keep semantic highlighting enabled for richer language support.
- Install Zenkai Theme Pro if you want file icons and developer product icons across the workbench.
